# Green Tea Production System Metabolomics

This repository contains the data and R scripts used for the analysis of green tea samples produced under three production systems: conventional (CON), ecological low-carbon (ELC), and organic (ORG).

The study integrates baseline compositional analysis, untargeted metabolomics, machine-learning-based classification, chemical class analysis, and cellular antioxidant-related assays.

## Repository structure

### data
- `all_metab_data.txt`: processed untargeted metabolomics data used for downstream analyses.
- `anno.xls`: metabolite annotation information.

### script
- `01_Metabolomics_annotation_...R`: metabolite annotation and annotation screening.
- `02_QC_evaluation_for_untargeted_...R`: quality-control assessment of the untargeted metabolomics data.
- `03_baseline_nutritional_composition.R`: analysis of baseline nutritional composition.
- `04_differential_metabolite_analysis.R`: pairwise differential metabolite analysis among CON, ELC, and ORG groups.
- `05_machine_learning_classification_and_feature_selection.R`: multinomial elastic-net and random-forest classification and feature prioritization.
- `06_chemical_class_composition_and_class_scores.R`: chemical class composition and class-score analysis.
- `07_Biochemical_assays_under_H...R`: analysis of antioxidant-related biochemical responses in the HFD-treated HepG2 cell model.

## Analysis workflow

The scripts are numbered according to the main analysis workflow and can be run sequentially where applicable.

Some scripts require intermediate files generated by preceding analyses. File paths may need to be adjusted according to the local working environment.

## Software

Analyses were performed in R using packages including `tidyverse`, `limma`, `glmnet`, `randomForest`, `caret`, `pROC`, `ggplot2`, and related packages.

## Data availability

The repository provides the processed data and analysis code required to reproduce the main statistical analyses and figures reported in the manuscript.
